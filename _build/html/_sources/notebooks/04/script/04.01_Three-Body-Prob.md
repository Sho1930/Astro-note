# 4. 多体問題

## 一般三体問題

```{admonition} Third body problem
:class: my-note
第 $i=1, 2,3$ 体の運動方程式は，その位置ベクトルを$\boldsymbol{r}_{i}(t)$，質量を$m_i$ ，時刻を$t$，重力定数を$G$とするとき，次式で与えられる．

$$
m_i \dfrac{d^2\boldsymbol{r}_i}{dt^2} = -\sum_{j \neq i}G m_i m_j \dfrac{\boldsymbol{r}_i-\boldsymbol{r}_j}{|\boldsymbol{r}_i-\boldsymbol{r}_j|^{3}}
$$
```




## 一般三体問題の数値解
`````{admonition} Three Body Problem (Chaos)
:class: my-code

```{code-block} julia
function eom_3bp_IF!(dx, x, p, t)
    # relative position
    r12 = ((x[1] - x[3])^2 + (x[2] - x[4])^2)^1.5
    r23 = ((x[3] - x[5])^2 + (x[4] - x[6])^2)^1.5
    r31 = ((x[5] - x[1])^2 + (x[6] - x[2])^2)^1.5

    # dr/dt = v
    dx[1:6] = x[7:12]
    
    # dv/dt = F/m
    dx[7]  = G * m2 * (x[3] - x[1]) / r12 + G * m3 * (x[5] - x[1]) / r31
    dx[8]  = G * m2 * (x[4] - x[2]) / r12 + G * m3 * (x[6] - x[2]) / r31

    dx[9]  = G * m1 * (x[1] - x[3]) / r12 + G * m3 * (x[5] - x[3]) / r23
    dx[10] = G * m1 * (x[2] - x[4]) / r12 + G * m3 * (x[6] - x[4]) / r23

    dx[11] = G * m1 * (x[1] - x[5]) / r31 + G * m2 * (x[3] - x[5]) / r23
    dx[12] = G * m1 * (x[2] - x[6]) / r31 + G * m2 * (x[4] - x[6]) / r23
end
`````

`````{admonition} Demo of 3BP
# 質点の質量
m1, m2, m3 = 0.1, 0.1, 0.1

# 重力定数（この問題のために適当に選択）
G = 1.0

# 初期条件の設定
x0 = [-1.0, 0.0, 1.0, 0.0, 0.0, 1.7, -0.074, 0.1282, -0.074, -0.1282, 0.148, 0.0] 

# 時間範囲の設定
tspan = (0.0, 100.0)

# 問題の定義
prob = ODEProblem(eom_3bp_IF!, x0, tspan)

# 解の計算（Runge-Kutta-Fehlberg法）
@time sol = solve(prob, Vern7(), reltol = 1e-16, abstol = 1e-16)
`````
